# Dispensa PHP Interattiva

Una guida interattiva e modulare per apprendere PHP da zero fino ai concetti di OOP, sicurezza, database e molto altro, con esempi live e navigazione a sezioni.

---

## 📚 Contenuti

1. Introduzione a PHP  
2. Variabili e Tipi di dato  
3. Operatori  
4. Controlli condizionali e loop  
5. Funzioni  
6. Array e manipolazioni  
7. Form e sicurezza  
8. File system  
9. Database (PDO + MySQL)  
10. Sessioni & Login  
11. Programmazione orientata agli oggetti (OOP)  
12. Progettazione e mini-progetti  
13. Framework & MVC (base Laravel)

---

## ⚙️ Tecnologie

- **PHP 7/8**
- **HTML5 & CSS3**
- **Vanilla JavaScript**
- **PDO & MySQL**
- **MAMP**
